# Rock-Paper-Scissors-Game-C-
A simple and interactive Rock Paper Scissors game built in C++ where the user plays against the computer with random choices.

A simple and interactive **Rock Paper Scissors game** built using **C++**.  
This console application allows a user to play against the computer, which randomly selects its move.

---

##  Features
- User vs Computer gameplay  
- Random computer choice  
- Win, lose, and draw detection  
- Simple and clean console interface  

---

## 🛠 Technologies Used
- C++  
- Random number generation (`rand()` and `srand()`)  
- Conditional statements and loops
